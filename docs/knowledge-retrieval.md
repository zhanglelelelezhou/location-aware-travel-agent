# 旅行知识检索

## 这一版解决什么问题

天气和地点由实时工具提供，但“严重过敏时如何点餐”“地震时怎么办”“护照丢失后联系谁”属于需要来源依据的旅行安全知识。系统不让 LLM 凭参数记忆回答，而是先检索经过版本化的官方来源摘要，再把原始链接放进答案和 trace。

当前版本同时实现 BM25、稠密向量和 Reciprocal Rank Fusion（RRF）混合召回。实验没有把“加了向量”当作成功标准：只有冻结盲测证明综合收益后才会切换默认方案。本轮混合召回只有有限排序增益，拒答没有改善，因此生产默认仍为 BM25。

## 数据来源与快照

当前语料含 6 个短段落，覆盖食品过敏沟通、餐饮交叉接触、紧急电话、地震行动、护照遗失和就医求助。来源只使用：

- 日本消费者厅（Consumer Affairs Agency）；
- 日本政府观光局（Japan National Tourism Organization）。

正文是项目作者根据官方页面编写的短摘要，不复制整页内容。每条记录保存稳定 ID、标题、发布机构、URL、主题和关键词；语料顶层保存 `snapshot_date`。网页内容可能变化，回答应鼓励用户查看原始页面的最新版本。

语料文件：`src/travel_agent/data/knowledge/japan_travel_safety.json`

## 检索与输出契约

BM25 检索器对英文使用去停用词的小写单词，对中文使用双字特征并移除少量高频旅行词。标题、正文、主题和人工关键词进入索引；确定性排序使用分数降序和文档 ID 作为并列规则。低于 `1.0` 的结果被拒绝，避免仅因“日本”等常见词重合就生成安全建议。

稠密检索使用 [FastEmbed](https://github.com/qdrant/fastembed) 的 [`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2)，对查询与段落做 L2 归一化后计算余弦相似度。该模型支持多语句向量并采用 Apache-2.0 许可证；评测报告同时记录模型 ID 和 FastEmbed 版本。该依赖是可选项，默认 BM25 不导入 FastEmbed，也不会下载模型。模型缓存固定在项目内 `.cache/fastembed`，不提交 Git。

混合模式不直接相加两个不可比的原始分数，而是使用 RRF：分别对 BM25 和向量结果排序，再计算 `1/(60 + sparse_rank) + 1/(60 + dense_rank)`。候选还必须满足 BM25 `>=1.0` 或向量余弦 `>=0.60`；0.60 只使用开发集正例和难负例选定，冻结后才运行盲测。

`KnowledgeSearchResult` 包含：

- 原始查询、provider、检索方法和快照日期；
- passage 的稳定 ID、标题、正文、发布机构、原始 URL；
- 融合分数、BM25 分数、向量分数和排名；
- embedding 模型、稀疏/稠密阈值与检索方法。

`top_k` 被限制在 1–5。回答层最多使用前两个 passage，每段都附 Markdown 来源链接。检索分数仅表示相关性，不是医学正确性或实时有效性的证明。

## 冻结盲测消融

| 方法 | Hit@1 | Hit@3 | Recall@3 | MRR@3 | 拒答准确率 | 查询 P50 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| BM25 | 58.3% | 66.7% | 66.7% | 62.5% | 62.5% | 0.121 ms |
| 稠密向量 | 25.0% | 25.0% | 25.0% | 25.0% | 87.5% | 19.126 ms |
| BM25 + Dense RRF | 66.7% | 66.7% | 66.7% | 66.7% | 62.5% | 19.724 ms |

稠密检索在 0.60 阈值下过于保守，很多真正相关的跨语言语义改写没有超过阈值；阈值降低又会在开发集引入“签证材料”等误召回。RRF 修正了一条 BM25 首位排序，但没有提高 Hit@3/Recall@3，也继承了 BM25 的库外误召回。这是一个有用的负结果：对于只有 6 个短段落的领域知识库，通用句向量和全局阈值并不自动优于人工可解释的关键词特征。

延迟来自单机单次小样本运行，仅用于说明量级，不能作为稳定性能基准。因此默认 `KNOWLEDGE_RETRIEVAL=bm25`。下一轮应新增更多语料和独立盲测，在不消费当前盲测集的前提下比较领域/多语检索模型、按主题或 margin 校准的拒答，以及 cross-encoder Rerank。
